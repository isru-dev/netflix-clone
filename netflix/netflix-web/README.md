
# Netflix Clone - React Web Application

A high-performance Netflix front-end clone built with **React**, featuring real-time data fetching from the TMDB API and dynamic trailer playback.

## 🚀 Key Features
* **Dynamic Data Fetching:** Utilizes a custom **Axios** instance to communicate with the TMDB API.
* **Interactive UI:** Horizontal scrolling movie rows with high-visibility hover effects.
* **Intelligent Trailer Search:** Integrated `movie-trailer` and `react-youtube` to fetch and play trailers on demand.
* **Responsive Banner:** Auto-generating hero section with a smooth "fade-to-black" vignette effect.

## 🛠️ Technical Stack
* **Frontend:** React.js (Hooks, Functional Components)
* **Styling:** CSS3 (Flexbox, BEM methodology)
* **API:** TMDB (The Movie Database)
* **Libraries:** Axios, React-YouTube, Movie-Trailer



## ⚙️ Setup
1.  Clone the repository.
2.  Run `npm install`.
3.  Create an account at [themoviedb.org](https://www.themoviedb.org/) to get an API Key.
4.  Add your key to `requests.js`.
5.  Launch with `npm run dev`.
